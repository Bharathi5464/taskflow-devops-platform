# TaskFlow – End-to-End DevOps CI/CD Platform

## Overview

The project focuses on building, automating, deploying, and monitoring a Python Flask REST API using industry-standard DevOps tools and workflows.

> **Current Status:** Project Foundation (Phase 0)

---

## Project Goal

Build one complete production-style DevOps platform that demonstrates:

- Version Control
- Containerization
- CI/CD Automation
- Kubernetes
- Helm
- Monitoring & Observability
- Infrastructure as Code
- Cloud Deployment
